Cultura Digital

La Cultura Digital es una disciplina que estudia cómo las tecnologías de la información y la comunicación transforman la manera en que aprendemos, trabajamos, nos relacionamos y resolvemos problemas. En un mundo cada vez más conectado, comprender las herramientas digitales y sus aplicaciones resulta esencial para el desarrollo académico, profesional y personal. Esta materia integra conocimientos sobre protección de datos en la web, licencias de software, directorios empresariales, criterios de búsqueda y técnicas de lectura rápida, que permiten al estudiante desenvolverse con seguridad y eficacia en entornos digitales. Asimismo, aborda el uso de redes sociales como TikTok, Instagram y Facebook, la creación de documentos en Word, el manejo de Excel básico y el estudio de unidades de almacenamiento, fortaleciendo competencias para la comunicación y la gestión de información. En su parte más técnica, Cultura Digital introduce al alumno en la programación con PSeInt y C++, explorando estructuras como switch, if y ciclos while, además de metodologías para la resolución de problemas. Estas herramientas fomentan el pensamiento lógico, la creatividad y la capacidad de diseñar soluciones tecnológicas aplicables en distintos contextos. En conjunto, la materia busca formar estudiantes capaces de utilizar la tecnología de manera crítica, responsable y productiva, preparándolos para enfrentar los retos de la sociedad digital actual y aprovechar las oportunidades que ofrece la innovación tecnológica.

Protección de información en la web

La protección de la información en la web implica resguardar los datos personales y sensibles frente a accesos no autorizados, pérdidas o usos indebidos. Esto se logra mediante contraseñas seguras, cifrado, autenticación de dos factores y buenas prácticas de navegación. Es esencial para preservar la privacidad, evitar fraudes y cumplir con normativas legales

Estafas en la web

Las estafas en línea son engaños diseñados para obtener dinero o información personal. Incluyen phishing, sitios falsos, fraudes románticos y estafas por redes sociales. Los estafadores suelen usar tácticas de urgencia o suplantación de identidad para manipular a las víctimas. La educación digital y el uso de software de seguridad son claves para prevenirlas




Licencias de software

Una licencia de software es un contrato legal que define cómo se puede usar un programa. Existen licencias propietarias (como Microsoft Office), libres (como GNU GPL) y de código abierto. Elegir la licencia adecuada garantiza el uso legal del software y protege los derechos del desarrollador

Directorio empresarial

Un directorio empresarial es una plataforma que agrupa información de empresas, como nombre, ubicación, servicios y contacto. Facilita la visibilidad online, la búsqueda de proveedores o clientes y la comparación entre negocios. Es útil tanto para consumidores como para emprendedores

Criterios de búsqueda

Los criterios de búsqueda son estrategias para encontrar información relevante en internet. Incluyen el uso de palabras clave precisas, operadores booleanos (AND, OR, NOT), filtros por fecha o tipo de archivo, y evaluación de la fuente (autoridad, actualidad, objetividad). Aplicarlos mejora la eficiencia y calidad de la información obtenida

Técnicas de lectura rápida

Las técnicas de lectura rápida permiten aumentar la velocidad de lectura sin sacrificar la comprensión. Incluyen el escaneo visual, la lectura en bloques, la eliminación de subvocalización y el uso de guías visuales. Son útiles para estudiantes y profesionales que manejan grandes volúmenes de texto

Estructura de documento word

Un documento en Word debe tener una estructura clara: portada, índice, introducción, desarrollo, conclusiones y bibliografía. Word ofrece herramientas como estilos, encabezados, numeración, tablas de contenido y secciones para organizar y presentar la información de forma profesional.

Redes sociales: Crear cuenta de Facebook, Instagram y Tiktok para empresas

Estas plataformas permiten compartir contenido y conectar con audiencias. TikTok se enfoca en videos cortos y virales; Instagram en imágenes y reels; Facebook en comunidades y eventos. Cada una tiene públicos y formatos distintos, lo que influye en su uso personal o comercial

Politicas redes sociales para cuentas de negocio

Las políticas de redes sociales establecen normas sobre cómo una empresa y sus empleados deben interactuar en línea. Incluyen lineamientos sobre tono, privacidad, manejo de crisis y uso de cuentas oficiales. Son esenciales para proteger la reputación de la marca y evitar conflictos legales

Unidades de almacenamiento

Son dispositivos que guardan datos de forma temporal o permanente. Se clasifican en magnéticas (discos duros), ópticas (CD/DVD), electrónicas (SSD, USB) y en la nube. Cada tipo tiene ventajas en velocidad, capacidad y portabilidad

Curso básico de Excel

Excel es una herramienta de hojas de cálculo que permite organizar, analizar y visualizar datos. Un curso básico enseña a usar celdas, fórmulas (SUMA, PROMEDIO), gráficos, filtros y tablas. Es fundamental para tareas administrativas, académicas y de análisis de datos

herramientas de Pseint

PSeInt es un entorno educativo que ayuda a aprender lógica de programación con pseudocódigo. Sus principales herramientas son: Editor de pseudocódigo: para escribir algoritmos paso a paso. Depuración paso a paso: permite ejecutar línea por línea y observar cómo cambian las variables. Diagramas de flujo: convierten el pseudocódigo en representaciones gráficas. Ejecutor automático: corre el algoritmo completo y muestra resultados. 👉 Es ideal para principiantes porque reduce la complejidad de lenguajes como C++ o Java.

Pseint switch

La estructura SEGÚN en PSeInt funciona como un menú de opciones que evalúa el valor de una variable y ejecuta el bloque correspondiente. Es más ordenada que usar múltiples SI...SI NO.
SEGÚN variable HACER
OPCIÓN 1:
// instrucciones
OPCIÓN 2:
// instrucciones
DE OTRO MODO:
// instrucciones por defecto
FINSEGÚN

Metodologias para la resolución de problemas

Metodologías para la resolución de problemas Resolver problemas en programación requiere un enfoque sistemático: Identificación del problema: definir claramente qué se quiere lograr. Análisis: descomponerlo en partes más pequeñas. Diseño de la solución: elegir estructuras (condicionales, ciclos, funciones). Implementación: escribir el código o pseudocódigo. Prueba y depuración: verificar que funciona y corregir errores. Documentación: explicar el proceso para que otros lo entiendan. 👉 Ejemplo: calcular el promedio de calificaciones requiere identificar entradas (notas), proceso (sumar y dividir), y salida (promedio).

Dev C++ Cout Cin

En C++, cout y cin son las funciones básicas de entrada y salida: cout (console output): muestra información en pantalla. cin (console input): recibe datos del usuario. Ejemplo:
#include
using namespace std;
int edad;
cout << "Ingresa tu edad: ";
cin >> edad;
cout << "Tu edad es: " << edad;

Dev C++ If

La estructura if permite tomar decisiones en el programa: Sintaxis básica:
if (condicion) {
// instrucciones si es verdadero
} else {
// instrucciones si es falso
}

C++ Ciclo while

El ciclo while repite un bloque de código mientras la condición sea verdadera.
while (condicion) {
// instrucciones }
